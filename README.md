# Minecraft Modpack Updater

Русская страница GitHub Pages и локальный обновлятор Windows для **полного клиента** Minecraft **1.20.1**, Forge **47.4.10**, Java **17**. Поддерживаются TLauncher и официальный Minecraft Launcher со стандартной `.minecraft` или собственной папкой игры.

Состав закреплён: **23 мода**, включая Embeddium, Oculus, Create, JEI, Jade, Xaero; **BSL 10.1.5**, **MPLOCmods 40.1**, 19 безопасных файлов настроек. Новый набор: AEM **1201.1.136**, Scalable Cat’s Force **3.3.1-build-0**, ServerTabInfo **1.20-1.3.8**. Неизвестных JAR в исходном составе нет (`unresolved: []`).

## Запуск

1. Нажмите **«Скачать обновлятор для Windows»** на странице GitHub Pages. Браузер загрузит две части, проверит SHA256 каждой и целого архива и сохранит обычный `Minecraft-Modpack-Updater-Windows.zip`. Распакуйте ZIP и запустите `Minecraft-Modpack-Updater.exe`. Это переносимое приложение: Python и права администратора не нужны. EXE не имеет подписи издателя. Проверяйте SHA256 из `docs/downloads/SHA256SUMS.txt`; при запрете запуска политикой устройства используйте проверенный исходный код или обратитесь к администратору, не отключайте защиту.
2. **r6 сам найдёт папки игры**, Java 17 и Forge. В списке сборок показаны лаунчер/расположение, название, версия по доступным метаданным и количество модов. Единственный вариант подставится сам; если вариантов несколько, выберите нужный. И официальный Launcher, и TLauncher могут использовать `%APPDATA%/.minecraft` или другую папку: ограничения по названию лаунчера нет. Переносить игру не нужно. «Другая папка…» добавляет вашу папку к ограниченному поиску.
3. Нажмите «Проверить». Закройте Minecraft, лаунчеры и Java-приложения, затем нажмите «Установить / обновить». Кнопка «Откатить» восстанавливает предыдущую операцию.

Исходный вариант: Python 3.11+ с tkinter, команда `python updater.py` или `Start.cmd`. PowerShell и изменение ExecutionPolicy не используются.

**TLauncher:** выберите Forge 1.20.1 / 47.4.10, папку конкретной сборки и ту же Java 17. Обновлятор не изменяет настройки TLauncher.

**Официальный Launcher:** выберите установку Forge 1.20.1-47.4.10. Если «Папка игры» не переопределена, используется `%APPDATA%/.minecraft`; именно её предлагает обновлятор. Если путь переопределён, выберите тот же путь в обновляторе. Общий `launcher_profiles.json` не читается и не перезаписывается. Проверка метаданных подтверждает наличие Forge, а не выбранную сейчас установку Launcher и не целостность всех его библиотек. Перед записью показываются конкретная папка и список изменений; создаётся backup затрагиваемых файлов.

Новая отдельная сборка — **необязательная** возможность. Кнопка «Создать отдельную сборку» создаст `Minecraft-AEM` в выбранном месте и скопирует путь. Только если используете эту новую папку, укажите её также в установке Forge в лаунчере. Существующую игру и данные переносить не требуется.

Forge и Java устанавливаются отдельно: [Forge 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html), [Temurin Java 17](https://adoptium.net/temurin/releases/?version=17). Обновлятор проверяет их выбранные версии и устанавливает моды/дополнения. Он не запускает игру.

**Если Java 17 не найдена:** r6 покажет фактически обнаруженные версии Java. Кнопка **«Java 17…»** открывает [официальный Temurin 17 для Windows x64](https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64&package=jdk): скачайте MSI, установите и повторите поиск. Для нестандартного места установки остаётся «Указать…». Запуск Minecraft не гарантирует, что лаунчер установит Java 17. Имя runtime Delta/Gamma не заменяет проверку `java -version`.

Автопоиск ограничен `runtime`, `jvms`, `jre`, `java` и `versions` внутри `%APPDATA%/.minecraft`, `%APPDATA%/.tlauncher` и выбранной папки игры. Для выбранного профиля внутри `versions` проверяются также эти подкаталоги его лаунчера. Только `bin/java.exe` (глубина до 5, до 160 каталогов и 12 Java-кандидатов) и конкретные `<версия>/<версия>.json` (до 120 каталогов версий на корень). Общие профили, аккаунты и токены не открываются. Поиск проверяет версии и ничего не переустанавливает.

Для папок игры проверяются стандартные `.minecraft`, `.tlauncher`, профили `versions/<имя>` **с собственным `mods`**, а также выбранная вручную папка и её ближайшие подпапки. Каталог установленной версии без своего `mods` не выдаётся за отдельную сборку. В `mods` считаются только имена JAR; на этапе поиска их содержимое не читается. Поиск не заходит в saves/config/аккаунты и не запускает Minecraft. Список отражает доступные метаданные, а не активную установку лаунчера; один и тот же gameDirectory может использоваться обоими лаунчерами.

Для Java дополнительно проверяются только каталоги версий 17 в известных `%ProgramFiles%/Eclipse Adoptium`, `Microsoft`, `Java`, `Zulu` (до 40 имён на поставщика). Весь Program Files и диск не сканируются.

## HTTPS в Windows

r6 скачивает файлы через **WinHTTP/SChannel**, системный HTTPS-стек Windows. Проверяются цепочка доверия, имя, срок действия и отзыв сертификата; не используются флаги игнорирования сертификатов, отключение TLS или собственное доверие прокси. Автоматические HTTP-перенаправления, cookies и аутентификация отключены. Точный размер и SHA256 обязательны после загрузки.

Ошибка `CERTIFICATE_VERIFY_FAILED` в r5 сама по себе не доказывает отсутствие CA внутри EXE: Python на Windows использует системные хранилища Root/CA, но построение цепочки и сетевое окружение могут отличаться от системного HTTP. По одному скриншоту причина на другом ПК не устанавливается. Новый транспорт использует штатную цепочку Windows без ослабления проверки.

Если Windows тоже отклонит соединение, сообщение покажет `cdn.modrinth.com`, код WinHTTP и доступную причину TLS. В каталоге backup текущей попытки будет `download-error.json`: только время, домен, код и причина, без аккаунтов, токенов и личных путей. Проверьте дату/время Windows, обновления корневых сертификатов и доступ к домену через вашу сеть. Не отключайте проверку сертификатов или антивирус глобально. До успешного получения и SHA256 всех файлов установка профиль не меняет.

Документация: [WinHTTP options](https://learn.microsoft.com/en-us/windows/win32/winhttp/option-flags), [Python SSL default certificates](https://docs.python.org/3/library/ssl.html#ssl.SSLContext.load_default_certs).

## Гарантии границ

- Только явно выбранная локальная папка игры. Сетевые диски, UNC, symlink и junction запрещены. Весь компьютер не сканируется.
- Моды скачиваются по закреплённым HTTPS URL `cdn.modrinth.com`. Проверяются точный размер и SHA256; HTTP-перенаправления запрещены. Сам манифест закреплён SHA256 внутри программы. Для следующего набора скачайте новый выпуск приложения.
- До записи скачиваются и проверяются **все** необходимые файлы. Для каждой операции сохраняются журнал, предыдущие и новые байты. Управляемые файлы заменяются атомарно; при ошибке выполняется откат. После прерывания питания следующий запуск требует сначала выполнить откат.
- Посторонние моды сохраняются. Коллизия имени, другого mod ID той же библиотеки/мода или language provider останавливает установку. Совместимость произвольных дополнительных модов не гарантируется.
- Совпадающий по хешу JAR с другим именем принимается без создания дубликата. Управляемая старая версия заменяется только если её предыдущий SHA256 совпадает с журналом состояния. Проекты, исчезнувшие из будущего манифеста, не удаляются автоматически.
- Существующие `config` и `options.txt` **никогда не перезаписываются установкой**. 19 проверенных файлов добавляются только при отсутствии. В новую папку переносятся выбранные настройки графики и ресурс-пака; аккаунты, серверы и персональные привязки клавиш не переносятся.
- `saves`, данные/метки Xaero, аккаунты, токены, списки серверов, логи и общие профили лаунчера не читаются, не копируются и не отправляются. Файл hardware fingerprint Embeddium исключён. JAR, shader ZIP и resource ZIP не входят в поставку: загружаются с официальных страниц авторов.
- Для проверки закрытия игры используются только имена процессов. Аргументы команд, окружение и учётные данные процессов не запрашиваются. Фоновых служб, автозапуска, планировщиков задач нет.

Backup находится в `<выбранная папка>/.modpack-updater/backups`. Откат сначала проверяет **все** затрагиваемые пути и резервные копии. Если после установки файл изменён, откат останавливается до записи. Это относится и к созданным настройкам, которые игра успела изменить. Не удаляйте backup до проверки результата. Откат модов не является откатом мира; сохранения не изменяются.

Страница может проверить SHA256 JAR через File System Access API после явного выбора папки в Chrome/Edge. Она не записывает файлы, не запускает EXE и не проверяет Java сама. Нет аналитики и передачи содержимого папки; обычные запросы страницы к GitHub Pages и загрузок к CDN видны этим хостингам.

## Данные и лицензии

`manifest.json` содержит все версии, официальные страницы/URL, идентификаторы Modrinth, размеры, SHA256, SHA512 и лицензии модов. SHA512 каждого исходного артефакта сопоставлен локально с публичным каталогом релизов Modrinth; локальные хеши не отправляются API. Имена трёх исходных JAR отличаются от официального имени загрузки, но байты совпадают; сохранены клиентские имена.

`presets/` содержит только явно проверенные настройки. Оригинальные имена профиля, имя пользователя Windows, адрес сервера и ники друзей в артефактах отсутствуют. Пользовательская оптимизация не менялась. MIT-лицензия этого репозитория относится к коду обновлятора и странице; сторонние моды/дополнения сохраняют собственные лицензии на официальных страницах.

## Проверки и сборка

```text
python -m unittest -v
python updater.py --self-test
python -m pip install -r requirements-build.txt
python build_release.py
```

`build_release.py` собирает Windows EXE, пользовательские архивы для страницы и SHA256SUMS. `split_download.py` делит Windows ZIP на две части меньше 8 МБ; страница соединяет их обратно без изменения байтов. Метаданные частей находятся в `docs/downloads/windows-download.json`. Исходный Windows ZIP не нужно загружать в GitHub: для Pages достаточно двух `.part` файлов и JSON. Сборка не требует Minecraft. Тесты используют только временные профили и синтетические JAR; игру и NAS не изменяют.

## Публикация именно в GitHub Pages

Назначение: https://github.com/lucifervalter-a11y/minecraft-modpack-updater

Загрузите содержимое репозитория, включая `docs/downloads`, в ветку `main`. В Settings → Pages выберите **Deploy from a branch**, **main**, **/docs**, Save. Это штатная [настройка GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site). Дополнительный deploy workflow не нужен.

Нужны права на запись содержимого репозитория; включение/изменение Pages требует прав администратора репозитория. Запросы изменения security settings, отключения защиты Windows или доступа к NAS для работы продукта не нужны.

Ожидаемый адрес после публикации: `https://lucifervalter-a11y.github.io/minecraft-modpack-updater/`. До подтверждения HTTP 200 и проверки кнопок этот адрес нельзя считать опубликованным.
