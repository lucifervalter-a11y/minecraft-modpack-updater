01

Выберите свой лаунчер

Один набор файлов. Два понятных способа подключения.

В TLauncher выберите Forge 1.20.1 / 47.4.10 и папку своей сборки — ту, внутри которой находится mods. Эту же папку укажите в обновляторе.

r8 поддерживает профиль с именем Mods: если Minecraft открыл …/versions/Mods/mods, выберите в обновляторе …/versions/Mods. Файл версии Forge не определяет активную папку игры. Итог можно скопировать кнопкой «Скопировать результат».

Исходники / Python

Одним нажатием: браузер подготовит обычный ZIP и проверит SHA256.

Распакуйте ZIP и запустите Minecraft-Modpack-Updater.exe. Python не нужен. Установщик не подписан сертификатом издателя; исходный код и SHA256 архивов открыты. Обходить защиту Windows не требуется.

МОЖНО СНАЧАЛА ПРОВЕРИТЬ

Что уже есть в папке?

Браузер читает моды только после вашего явного выбора папки. Содержимое не отправляется на сервер. Java и Forge проверяются в локальном обновляторе.

Папка ещё не выбрана. Доступа к диску нет.

    Три шага до готовой сборки

    02

    Подтвердите найденную сборку

    r8 сам найдёт папки игры, Java 17 и Forge. В списке — название сборки, версия и число модов. Если папка одна, она подставится сама; если несколько — выберите нужную. .minecraft подходит обоим лаунчерам.

    03

    Проверьте и установите

    Закройте игру и лаунчеры. «Проверить» только сверяет файлы и показывает счётчик. Для установки нажмите «Установить / обновить». Все загрузки начинаются по вашей кнопке, идут с официального CDN и проверяются по SHA256. В Windows используется системный HTTPS с проверкой сертификатов.

    ↶

    При необходимости откатите

    Обновлятор хранит backup каждой операции в выбранной папке. «Откатить» возвращает предыдущие файлы. Если файл изменён после установки, откат остановится и сохранит его.

    Ваше остаётся вашим

    Оптимизация сохранена
    Точные версии всех 28 модов. Существующие config и options.txt остаются как есть. Безопасные настройки добавляются только там, где файла ещё нет.

    Личные данные остаются локально
    Аккаунты, токены, saves и метки Xaero не читаются. Файлы общих профилей лаунчеров не перезаписываются. NAS и другие папки не сканируются.

    Посторонние моды остаются
    Обновляются только управляемые файлы. При конфликте версий установка останавливается. Совместимость дополнительных модов требует отдельной проверки.

    Forge или Java ещё не установлены?

    r8 покажет найденные версии Java. Если Java 17 нет, кнопка «Java 17…» в приложении откроет официальный установщик Temurin: выберите Java 17, Windows x64, MSI. После установки повторите поиск. Запуск Minecraft сам по себе не гарантирует установку Java 17. Также можно открыть официального Temurin. Forge 47.4.10 находится в официальном каталоге Forge для 1.20.1. Этот обновлятор устанавливает моды и проверяет выбранные Java и метаданные Forge; сами Java и Forge устанавливаются отдельно.

    В официальном Launcher сначала запустите Minecraft 1.20.1, затем установите Forge. Выберите установку Forge. Её стандартная .minecraft поддерживается; при своём gameDirectory укажите его в обновляторе. Общую установку и аккаунты обновлятор не редактирует. В TLauncher укажите ту же версию Forge и отдельную папку.

    Как получать будущие обновления?

    Скачайте новый выпуск обновлятора с этой страницы и выберите ту же папку. Он сверит закреплённый манифест и предложит изменения управляемого набора. Фоновых служб, автозапуска и автоматической замены версий нет.
